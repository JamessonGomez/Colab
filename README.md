## Introdução ao Google Colab

O [Google Colab](https://colab.research.google.com/) é um serviço de notebooks Jupyter hospedado que permite executar código Python sem configurar um ambiente local. Conforme a disponibilidade e as condições do serviço, oferece acesso a recursos de computação como GPUs e TPUs.

É utilizado principalmente em aprendizado de máquina, ciência de dados, pesquisa e educação.
