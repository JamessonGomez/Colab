# Como contribuir

Obrigado por ajudar a melhorar este repositório.

## Antes de enviar uma alteração

- Verifique se o conteúdo é claro, correto e adequado ao público-alvo.
- Prefira fontes oficiais e referências atualizadas para afirmações técnicas.
- Preserve a organização dos materiais e use títulos hierárquicos.
- Escreva em português do Brasil, salvo quando termos técnicos ou nomes oficiais exigirem outro idioma.
- Não inclua credenciais, tokens, dados pessoais ou informações confidenciais.

## Padrão para arquivos Markdown

- Use um único título principal (`#`) por arquivo.
- Separe títulos e listas com linhas em branco.
- Use títulos descritivos e listas para facilitar a leitura.
- Prefira links com texto explicativo em vez de URLs soltas.
- Revise ortografia, acentuação e consistência dos termos.

## Fluxo de contribuição

1. Crie uma branch a partir de `main`.
2. Faça alterações pequenas e focadas.
3. Revise o diff e execute a verificação de Markdown localmente, se possível.
4. Abra um pull request descrevendo o objetivo, as mudanças e como foram verificadas.
5. Aguarde a revisão antes de mesclar.

## Verificação automática

O GitHub Actions executa o Markdownlint nos arquivos `.md` em cada pull request e em atualizações da branch principal. Corrija os problemas apontados antes de solicitar aprovação.
